Camera-ready instructions for ALT 2025

Congratulations on your accepted ALT 2025 paper! The paper will be published in Proceedings of Machine Learning Research (PMLR), volume 272.

While preparing the "camera-ready" (i.e., final) version of your paper, please take the reviews of your paper (available in OpenReview) into careful consideration. In accepting your paper, we assumed that the important remarks they contain would be addressed.

Note that there is no page limit, although the first 13 pages (the original 12 from submission, plus one more to address reviewer comments/concerns) should contain a clear presentation of the paper's main contributions and an outline of the main arguments.

The deadline for submitting the camera-ready version of your paper is February 3, 2025 11:59 pm AoE.

Instructions for preparing and submitting the camera-ready version are as follows.

Step 1: Update style file and generate camera-ready PDF

The style file for the camera-ready version can be found here:

http://www.gautamkamath.com/alt2025/alt2025-style-final.zip

The only change from the style file from submission is the inclusion of the volume number.

In your main TeX source file, you will need to change the options to documentclass:

\documentclass[final,12pt]{alt2025}

Please do not modify any aspects of the default formatting (e.g., spacing, margins, fonts). Packages that change margins or fonts (e.g., "fullpage", "geometry") should be removed or disabled.

If you are opting to submit an extended abstract instead of a full paper, your extended abstract should be formatted in the same manner as a standard paper (including a short abstract section), be at least one page long (excluding references; see example from a previous year here), and include a link to the arXiv version of the full paper in a footnote on the first page with the following text:

Extended abstract. Full version appears as \citep{citation of the full version}.

Recompile the PDF of your paper using this style file (and with the proper footnote if appropriate).

The <key> part of the BibTeX filename (<key>.bib) is generated in accordance with the PMLR specifications based on the last name of the paper's first author, the last two digits of the conference year, and possibly a suffix character for disambiguation. You will need to use this same <key> in later steps.

The BibTeX entry should be formatted as follows:

  @inproceedings{<key>,
    author     = {Paper authors in "Lastname, Firstnames" format, separated by "and"},
    title      = {Paper title},
    pages      = {},
    abstract   = {Paper abstract},
    openreview = {OpenReview identifier}
  }

Please fix any errors in the title and author parts. They were automatically extracted them from OpenReview.

Leave the pages part empty, but fill in the abstract part with your paper's abstract. You should explicitly expand any custom macros and citation commands. Please also heed the following rules from PMLR for the abstract:

  • It can include maths in valid LaTeX.
  • Make sure there are no special characters in the abstract, such as those arising from copying and pasting ligatures from the pdf.
  • You can use <em> tags for emphasis.
  • You can use <b> for bold.
  • You can use <ul> tags for bullets.
  • You can use <ol> for numerated lists.

Step 3: Sign copyright form

Download and digitally sign (or print out, sign, and scan) the copyright form, which can be found here:

http://proceedings.mlr.press/pmlr-license-agreement.pdf

Only one author needs to sign. Please prepare this as a PDF file (i.e., no JPGs, GIFs, PNGs, TIFFs, etc).

Step 4: Rename, zip, and upload files

By this point, you will have the PDF of your camera-ready paper, the PDF of the signed copyright form, and the BibTeX file named <key>.bib.

Rename the PDF files using the same <key> from the BibTeX file as follows:

  • Camera-ready paper PDF: <key>.pdf
  • Signed copyright form PDF: <key>Permission.pdf

Create a ZIP file named <key>.zip containing

  • <key>.bib,
  • <key>.pdf, and
  • <key>Permission.pdf.
Navigate to your paper's page on OpenReview and upload a Camera-Ready Revision making sure to include both of the following a) your camera-ready PDF as PDF, and b) the ZIP file as Camera Ready Zip.

These requirements must be respected for the paper to be published. Please check carefully before sending. For any questions, please contact us at alt2025pc@gmail.com with the subject line "ALT 2025 camera-ready".

Thank you again for your contribution to ALT 2025.
